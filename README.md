## 🚀 Featured Projects

### 🛒 [Retail Sales & Inventory Intelligence Platform](https://github.com/balakrishnanpremnath/retail-intelligence-platform)

[![Release](https://img.shields.io/badge/Release-v1.0.0-2563EB?style=flat-square)](https://github.com/balakrishnanpremnath/retail-intelligence-platform/releases/tag/v1.0.0)
[![CI](https://github.com/balakrishnanpremnath/retail-intelligence-platform/actions/workflows/ci.yml/badge.svg)](https://github.com/balakrishnanpremnath/retail-intelligence-platform/actions/workflows/ci.yml)
![Synthetic Data](https://img.shields.io/badge/Dataset-Synthetic-64748B?style=flat-square)

Built an **end-to-end retail analytics and decision-support platform** integrating data engineering, machine learning, and business intelligence.

- Developed a **PostgreSQL dimensional warehouse** with Python ETL and analytical SQL views for **19,329 transactions, 4 stores, 30 products, and 500 customers**.
- Built interactive **Streamlit and Power BI dashboards** for sales, profitability, inventory, and customer analytics.
- Applied **RFM analysis and K-Means** to identify three customer segments; evaluated demand forecasting with Rolling-7, Poisson Regression, and Random Forest.
- Designed **7- and 14-day forecast-based inventory risk and replenishment scenarios**, backed by automated tests, Docker, and GitHub Actions CI.

**Tech:** `Python` · `PostgreSQL` · `SQL` · `Pandas` · `Scikit-learn` · `Streamlit` · `Power BI` · `Docker`

<sub>Note: Uses simulated retail data; forecasts and stock recommendations are illustrative, not live business predictions.</sub>

### 💬 [Spam Message Detector](https://github.com/balakrishnanpremnath/spam-message-detector)

Developed an **NLP-based SMS classification app** with TF-IDF, multiple machine learning models, and a Streamlit interface for individual and CSV batch predictions.

- A saved Linear SVM experiment achieved **0.957 spam F1** on **1,034 test messages**; the repository documents evaluation limitations.
- Included automated testing and GitHub Actions CI.

**Tech:** `Python` · `NLP` · `TF-IDF` · `Scikit-learn` · `Streamlit`

### 📊 [Sales Analytics Dashboard](https://github.com/balakrishnanpremnath/sales-analytics-powerbi)

Created a **three-page Power BI dashboard** for sales, customer, product, and regional performance using Power Query and DAX.

- Analyzed a practice dataset representing **LKR 115.80M in sales** and a **23.39% profit margin**.
- Added KPIs, interactive slicers, profitability analysis, and product comparisons.

**Tech:** `Power BI` · `DAX` · `Power Query` · `Data Visualization`

### ✈️ [Airline Data Warehouse](https://github.com/balakrishnanpremnath/airline-data-warehouse)

Implemented the technical solution for a **group academic data warehousing project**, covering incremental data loading, dimensional modeling, and historical tracking.

- Built source, staging, dimension, and fact tables with **Python and SQLite**.
- Implemented **SCD Type 2** passenger history and documented warehouse validation queries.

**Tech:** `Python` · `SQL` · `SQLite` · `ETL` · `Dimensional Modeling`

### 📈 [AAPL Stock Forecasting](https://github.com/balakrishnanpremnath/aapl-stock-forecasting)

Compared **naive, Prophet, and LSTM** methods for Apple stock closing-price forecasting using MAE and RMSE.

- The **naive baseline** achieved the lowest reported preliminary MAE (**8.07**), demonstrating the importance of comparing ML models against simple baselines.
- Documented the experiment's forecasting and evaluation limitations.

**Tech:** `Python` · `Pandas` · `Prophet` · `TensorFlow` · `Time Series`
