## 🚀 Featured Projects

### 💬 [Spam Message Detector](https://github.com/balakrishnanpremnath/spam-message-detector)

Built an SMS classification application using **TF-IDF, Scikit-learn, and Streamlit**, comparing Naive Bayes, Logistic Regression, and calibrated Linear SVM.

- Supports individual messages and CSV batch predictions.
- Saved Linear SVM experiment recorded **0.957 spam F1** on **1,034 test messages**.
- Includes automated tests and a GitHub Actions workflow.
- Results are developmental because the test set influenced final model selection.

**Technologies:** Python · NLP · TF-IDF · Scikit-learn · Streamlit

---

### 📊 [Sales Analytics Dashboard](https://github.com/balakrishnanpremnath/sales-analytics-powerbi)

Built a **three-page Power BI dashboard** using Power Query and DAX to explore sales, profitability, products, customers, and regions.

- Analyzes **2,990 cleaned practice-data records**.
- Dashboard snapshot represents **LKR 115.80M sales** and **23.39% gross profit margin**.
- Includes interactive slicers, KPI cards, and product performance comparisons.

**Technologies:** Power BI · Power Query · DAX · Data Visualization

---

### ✈️ [Airline Data Warehouse](https://github.com/balakrishnanpremnath/airline-data-warehouse)

Implemented the full technical solution for a group academic project using **Python, SQL, and SQLite**.

- Designed source, staging, dimension, and fact tables.
- Implemented incremental booking loads and **SCD Type 2** passenger history.
- Documented a two-run demonstration progressing from **20 to 21 booking facts**.
- Added analytical queries and validation checks.

**Technologies:** Python · SQL · SQLite · ETL · Dimensional Modelling

---

### 📈 [AAPL Stock Forecasting](https://github.com/balakrishnanpremnath/aapl-stock-forecasting)

Compared **naive, Prophet, and LSTM** approaches to Apple closing-price forecasting.

- Evaluated prediction errors using **MAE and RMSE**.
- The original experiment reported the lowest MAE for the naive baseline: **8.07**.
- Results remain preliminary while preprocessing and forecast-protocol issues are addressed.

**Technologies:** Python · Pandas · Prophet · TensorFlow · Time Series
