### 💬 [Spam Message Detector](https://github.com/balakrishnanpremnath/spam-message-detector)

Developed an **SMS spam classification application** using text preprocessing, **TF-IDF**, and Scikit-learn, with a Streamlit interface.

- Compared Naive Bayes, Logistic Regression, and calibrated Linear SVM.
- Supported individual SMS predictions and **CSV batch predictions**.
- Recorded **0.957 spam F1** for the saved Linear SVM experiment on **1,034 test messages**.
- Added automated tests and GitHub Actions CI.

**Technologies:** Python · NLP · TF-IDF · Scikit-learn · Streamlit

*Evaluation note: The test set influenced final model selection, so the reported result is developmental rather than an unbiased final benchmark.*
