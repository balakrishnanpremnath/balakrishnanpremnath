## 🚀 Featured Project

### 🛒 [Retail Sales & Inventory Intelligence Platform](https://github.com/balakrishnanpremnath/retail-intelligence-platform)

<a href="https://github.com/balakrishnanpremnath/retail-intelligence-platform/releases/tag/v1.0.0"><img src="https://img.shields.io/badge/Release-v1.0.0-2563EB?style=flat-square" alt="Version 1.0.0" /></a>
<a href="https://github.com/balakrishnanpremnath/retail-intelligence-platform/actions/workflows/ci.yml"><img src="https://github.com/balakrishnanpremnath/retail-intelligence-platform/actions/workflows/ci.yml/badge.svg" alt="Retail project CI" /></a>
<img src="https://img.shields.io/badge/Data-Synthetic-6B7280?style=flat-square" alt="Synthetic dataset" />

**End-to-end retail analytics and decision-support system** combining a PostgreSQL data warehouse, Python ETL, customer segmentation, demand forecasting, inventory risk analysis, **Streamlit** and **Power BI**.

| Project scale | Verified portfolio results |
|:--|:--|
| Retail dataset | **19,329 transactions** · **4 stores** · **30 products** · **500 customers** |
| Business overview | **LKR 82.75M revenue** · **20.08% profit margin** |
| Customer intelligence | **3 RFM + K-Means segments**: High Value (231), Loyal (190), At Risk (79) |
| Demand forecasting | Compared **Rolling-7, Poisson and Random Forest**; Rolling-7 achieved the lowest one-step MAE (**0.8619 units**) |
| Inventory decisions | Saved **7-/14-day forecasts**, stock-risk scenarios and explainable replenishment recommendations |
| Software quality | **72 passing tests** at the documented checkpoint · GitHub Actions CI · Docker Compose |

**Tech:** `Python` · `PostgreSQL` · `SQL` · `Pandas` · `Scikit-learn` · `Streamlit` · `Plotly` · `Power BI` · `Docker`

> **Data transparency:** This is a synthetic-data portfolio project, not a live business system. Forecasts and inventory recommendations are illustrative. Simpler forecasting baselines were retained where they performed better than more complex models.
